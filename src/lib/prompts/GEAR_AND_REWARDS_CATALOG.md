# GEAR & REWARDS CATALOG — Arise

All items, gear, titles, and rewards available in the game. The System awards these based on quest completion, milestones, and special events.

---

## GEAR SYSTEM

### Gear Slots
- **Weapon** (1 slot) — Boosts Attack
- **Armor: Helm** (1 slot) — Boosts Defense
- **Armor: Chest** (1 slot) — Boosts Defense
- **Armor: Legs** (1 slot) — Boosts Defense
- **Accessory** (3 slots) — Special effects

### Gear Ranks
Gear matches the rank system (E through S). Players primarily earn gear matching their current rank, with rare drops from one rank above.

## REWARD CHOICE SYSTEM

When completing a daily quest, the Player chooses ONE reward:
1. **Status Recovery** — Restore 20 HP + 20 MP + reduce fatigue by 10
2. **Stat Points** — Gain 1 bonus stat point (in addition to level-up points)
3. **Loot Box** — Receive a loot box matching current rank tier

This choice adds strategy — Players in critical HP might choose recovery, while those grinding might choose stat points.

---

## GEAR UPGRADE SYSTEM

Gear can be upgraded using gold:
- Each upgrade level costs: `(base_rank_value × upgrade_level) × 100` gold
- Maximum upgrade level: +5
- Each upgrade adds +2 ATK (weapons) or +2 DEF (armor) or enhances special effect (accessories)
- Rank base values: E=1, D=2, C=3, B=5, A=8, S=10
